## 🔬 Current Research

### 🚀 DialSort — Non-Comparative Integer Sorting

> **Order is not computed. It is revealed.**

A novel execution model based on the **self-indexing principle**, eliminating comparisons and prefix sums.

- ⚡ Up to ~40× faster than `std::sort` in bounded domains
- 🧠 Formal model + **Conflict Resolution Network (CRN)**
- 🎮 Interactive simulators
- 📄 Research paper in progress / arXiv soon

👉 https://github.com/elmaestrotic/dsort
